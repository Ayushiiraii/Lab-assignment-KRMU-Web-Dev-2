# 📅 Event Dashboard

A simple and interactive **Event Management Dashboard** built using **Vanilla JavaScript and DOM manipulation**.  
Users can add, view, and delete events dynamically without refreshing the page.

---

## 🚀 Features

- ➕ Add new events with:
  - Title
  - Date
  - Category
  - Description
- 🗑️ Delete individual events
- 🧹 Clear all events at once
- 📌 Add a sample event (for demo)
- 📭 Displays message when no events are present
- ⚡ Real-time UI updates using DOM

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (DOM Manipulation)

---

## 🧠 Core Concepts Used

- DOM Selection (`getElementById`, `querySelector`)
- Event Listeners (`click`)
- Dynamic Element Creation (`createElement`)

- Conditional Rendering
- Form Handling

## ⚙️ How to Run the Project

1. Download or clone the repository  
2. Open `index.html` in your browser  

---

## 💡 How It Works

- User enters event details and clicks **Add Event**
- A new event card is dynamically created and added to the UI
- Each card includes a delete button
- Users can:
  - Remove individual events
  - Clear all events
  - Add a sample event for testing
- If no events exist, a message is displayed
